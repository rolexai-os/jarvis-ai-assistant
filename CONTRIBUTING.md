# Contributing

Issues and pull requests are welcome.

1. Describe the bug or feature in an issue.
2. Keep pull requests focused and document behavior changes.
3. Add tests for core logic.
4. Run python -m unittest discover -s tests -v.
5. Never commit API keys, credentials, private data, screenshots, or .env files.

Safety rule: do not add arbitrary shell execution, hidden recording, or destructive actions without explicit user confirmation and clear documentation.
